# 接地判定の比較

作成日：2026-11-06（日本時間）  
対象：Gravity Shift / Unity 6000.3.25f1  
関連スクリプト：`Assets/_Game/Screpts/Player/GroundDetector2D.cs`

## このメモの目的

過去に試した接地判定のコードと、変更した理由を残す。次のゲームでは、当時の前提と未確認事項を読んでから参考にする。

ここに保存したコードは学習・比較用。すべてが完成済み・検証済みの推奨実装という意味ではない。現在使うコードは上記のスクリプトで管理し、このメモの記録を編集してもゲームには反映されない。

## 今回の前提と目指す動き

- 重力は上下左右の4方向。`GravityVector`は、そのいずれかの長さ1のベクトル。
- Player本体の物理コライダーは`BoxCollider2D`。Visualの向きと、本体のコライダーの向きは別に扱っている。

## 方法の比較

| 方法 | 調べる対象 | 得られる情報 | 今回の位置付け |
| --- | --- | --- | --- |
| 本体の`Collider2D.Cast` | 本体の形を指定方向へ動かしたときの検出対象 | `RaycastHit2D`。当たる位置・法線・距離など | 最初に試した方式 |
| 足元の`Physics2D.BoxCast` | 自由に配置・設定したBoxを動かしたときの検出対象 | `RaycastHit2D`。当たる位置・法線・距離など | 足元へ範囲を絞るために試した方式 |
| `Physics2D.OverlapBox` | 指定したBoxと重なるコライダー | `Collider2D`。法線は直接返さない | 比較候補。今回の実装として採用した記録はない |
| 本体の`Collider2D.GetContacts` | 本体の物理コライダーの接触情報 | `ContactPoint2D`。接触点・法線など | 保存時点で使用中。切り替え後の動作確認は未完了として記録 |

## 1. 本体のCollider2D.Cast

### 狙い

本体のコライダーの形を使い、重力方向へ短い距離を調べる。取得した候補から、法線を使って床を選ぶ。

### 以前使った呼び出し

```csharp
int hitCount = playerCollider.Cast(
    gravityController.GravityVector,
    contactFilter,
    groundHits,
    groundCheckDistance);
```

この版の`groundHits`は`RaycastHit2D[]`。

### 学んだこと

- 本体の形全体を使う。足元だけの小さい検知Boxとは異なる。
- 検出したすべての面を床にする必要はない。候補の取得と、床としての採用を分ける。
- 開始時に重なっているコライダーも検出される場合がある。`Collider2D.Cast`の公式説明では、初期重なりで法線を計算できない場合、発射方向の逆ベクトルを返すとされている。
- したがって、返った法線が常に地形の実際の面の法線である、とは扱わない。

## 2. 足元のPhysics2D.BoxCast

### 狙いと変更の経緯

Player本体を物理的に支えるコライダーはそのままに、接地を調べる範囲を足元へ絞ろうとした。

最初は足元へ本体に近い大きさのBoxを置いていた。その後、厚さを`0.1f`にして薄いBoxへ調整した。発射距離も、短い距離を指定する版、引数を省略した版、最後に`0f`を指定する版を試した。

### 足元Boxの設定

| 重力 | Boxの中心 | Boxの大きさ |
| --- | --- | --- |
| 下 | `bounds.center.x`, `bounds.min.y` | 本体の横幅−`0.1f`, 厚さ`0.1f` |
| 上 | `bounds.center.x`, `bounds.max.y` | 本体の横幅−`0.1f`, 厚さ`0.1f` |
| 左 | `bounds.min.x`, `bounds.center.y` | 厚さ`0.1f`, 本体の縦幅−`0.1f` |
| 右 | `bounds.max.x`, `bounds.center.y` | 厚さ`0.1f`, 本体の縦幅−`0.1f` |

`feelPosition`という変数名で中心を保持していた。`castSize`はBoxの全体の幅と高さ。角度の引数は`0f`だった。

```csharp
int hitCount = Physics2D.BoxCast(
    feelPosition,
    castSize,
    0f,
    gravityController.GravityVector,
    contactFilter,
    groundHits,
    0f);
```

### 参照するときの注意

- 最後の距離を省略した配列版の呼び出しは無限距離になる。距離省略は「動かさない」という意味ではない。
- 距離`0f`は移動距離0の指定。その結果の法線を、床の傾き判定に信頼して使えるかは、このプロジェクトで比較検証していない。
- 「その場の重なりだけ」が目的ならOverlapBoxも候補。ただし法線を直接返さないため、今のDot判定をそのまま移すことはできない。
- 中心が足元、厚さが`0.1f`なら、Boxは中心から両側へ`0.05f`ずつ広がる。重力方向の外側だけに配置されるわけではない。
- 幅から`0.1f`を引くのは、合計で`0.1f`の縮小。中心が同じなら左右`0.05f`ずつであり、「左右0.1ずつ」でも、常に「10%」でもない。
- `BoxCollider2D.size`はローカルの大きさ、`bounds`はワールド空間の情報。スケールや本体の回転を変える場合は、この混在を見直す。
- Physics2D.BoxCastは、本体のCollider.Castと違ってPlayerを自動で除外する前提にしない。GroundのレイヤーマスクへPlayerを含めない。
- 描いていたWireCubeは開始位置のBox。距離を指定した場合の、移動経路全体を描いていたわけではない。

### GetContactsを試すことにした理由

丸い床や斜面では、本体の箱の端が床に支えられていても、幅を狭くした足元Boxがその接触位置を拾えない可能性がある。

今回は、本体を支えている接触面を基準に床を選ぶ方法を試すことにした。BoxCast自体を一般に不適切と判断したわけではない。

## 3. 現在のCollider2D.GetContacts

### 保存時点の流れ

1. `isGrounded`をfalseへ戻す。
2. `playerCollider.GetContacts(contactFilter, groundHits)`で接触情報を受け取る。
3. 戻り値の件数まで、`ContactPoint2D[]`を読む。
4. `normal`と「重力の逆向き」をDotで比較する。
5. 基準を満たす接触があればtrueにしてループを終える。

### 引数と戻り値

| 要素 | 内容 |
| --- | --- |
| 呼び出す対象 | Player本体の`BoxCollider2D` |
| 第1引数 | `ContactFilter2D`。今回はGroundのレイヤーマスクを設定 |
| 第2引数 | `ContactPoint2D[]`。結果を書き込む配列。保存時点では8要素 |
| 戻り値 | 配列へ格納された接触点の数。相手オブジェクトの数とは限らない |

発射位置・サイズ・角度・方向・距離の引数はない。本体の物理コライダーについて管理されている接触を取得する。Triggerとの接触点は返らない。

### 床を選ぶ基準

```csharp
Vector2.Dot(hit.normal, -gravityController.GravityVector) > 0.7f
```

両ベクトルの長さが1なら、重力と逆向きの基準から約45.6度未満の面を採用する設定。四方向のどの重力でも同じ考え方を使える。

接触候補のうち横壁を取得しても、それだけで床になるわけではない。Dotの基準を満たす接触面を床として選ぶ。

### 残っている確認・調整

- [ ] 平地に立つとtrue、空中ではfalseになる。
- [ ] 空中で横壁に触れても床として採用しない。
- [ ] 上下左右の各重力で、床となる面を採用できる。
- [ ] 緩い斜面・基準を超える急斜面・大きな円の上側で確認する。
- [ ] ジャンプ直後・着地・重力切り替え直後の更新タイミングを確認する。
- [ ] 接触が8件に達する状況があれば、結果が配列容量に制限されていないか確認する。

コードの置き換えは確認したが、GetContacts版の上記テストがすべて成功したという報告は、保存時点では受けていない。

坂に沿う移動は未実装の別作業。接地判定をGetContactsに変えただけで、下り坂への追従や停止中の滑りまで解決するわけではない。

using System.Drawing;
using UnityEngine;

public class GroundDetector2D : MonoBehaviour
{

    // 重力の方向を取得するためにGravityControllerを参照
    [SerializeField] GravityController gravityController;

    // 接地判定のための当たり判定
    BoxCollider2D playerCollider;

    // 接地判定のためのレイヤーマスク
    [SerializeField] LayerMask groundLayerMask;

    // 接地判定までの距離を設定するための変数
    [SerializeField] float groundCheckDistance = 0.05f;

    // 接地判定の結果を保持するための配列(仮で8)
    // 本体のBoxが触れている面を取得して、その中から床を選ぶために、複数の接触点を取得する必要がある
    RaycastHit2D[] groundHits = new RaycastHit2D[8];

    // 接地判定の条件を設定するための変数
    ContactFilter2D contactFilter;

    //接地状態のフラグ
    bool isGrounded = false;

    // 接地判定のための発射位置を保持する変数
    Vector2 feelPosition = new Vector2();

    // 接地判定のためのCastの大きさを保持する変数

    Vector2 castSize = new Vector2();

    void Awake()
    {
        playerCollider = GetComponent<BoxCollider2D>();

        // 接地判定の条件
        contactFilter = new ContactFilter2D();
        contactFilter.SetLayerMask(groundLayerMask);
        contactFilter.useTriggers = false;

    }

    void FixedUpdate()
    {
        isGrounded = false;

        // 【Castの実行】自身を無視して重力的下方向に発射する(判定の大きさは自身のコライダー+groundCheckDistance)
        // ヒットした数が0より多ければ「地面がある」と判定

        // 重力によるPLayerの足元の位置を計算する
        // 重力の向きによって、接地判定の方向を変える
        float offsetX = 0f;
        float offsetY = 0f;

        switch (gravityController.GravityVector)
        {
            case { x: 0, y: 1 }:
                // 上の処理
                offsetX = playerCollider.bounds.center.x;
                offsetY = playerCollider.bounds.max.y;

                feelPosition = new Vector2(offsetX, offsetY);
                break;

            case { x: 0, y: -1 }:
                // 下の処理
                offsetX = playerCollider.bounds.center.x;
                offsetY = playerCollider.bounds.min.y;

                feelPosition = new Vector2(offsetX, offsetY);
                break;

            case { x: -1, y: 0 }:
                // 左の処理
                offsetX = playerCollider.bounds.min.x;
                offsetY = playerCollider.bounds.center.y;

                feelPosition = new Vector2(offsetX, offsetY);
                break;

            case { x: 1, y: 0 }:
                // 右の処理
                offsetX = playerCollider.bounds.max.x;
                offsetY = playerCollider.bounds.center.y;

                feelPosition = new Vector2(offsetX, offsetY);
                break;

            default:
                // その他の処理
                break;
        }

        // 当たり判定の大きさを作成（横幅を「一回り小さく」調整する（例: 90%のサイズにする））
        float widthReduction = 0.1f; // 横幅を0.1ずつ削る
        float heightThickness = 0.1f; // 厚さを指定する

        switch (gravityController.GravityVector)
        {
            case { x: 0, y: 1 }:
            case { x: 0, y: -1 }:
                // 上下方向の重力の場合、横幅を縮小
                castSize = new Vector2(playerCollider.size.x - widthReduction, heightThickness);
                break;

            case { x: -1, y: 0 }:
            case { x: 1, y: 0 }:
                // 左右方向の重力の場合、縦幅を縮小
                castSize = new Vector2(heightThickness, playerCollider.size.y - widthReduction);
                break;

            default:
                // その他の処理
                break;
        }

        // 旧：接地判定のためのCastを実行（方向ベクトル、検知条件、結果を格納する配列、距離）
        // int hitCount = playerCollider.Cast(gravityController.GravityVector, contactFilter, groundHits, groundCheckDistance);

        // 接地判定を行うためPhysics2DでのCastを実行（発射位置、Boxサイズ、Box回転、飛ばす方向、検知条件、結果を格納する配列、距離）
        int hitCount = Physics2D.BoxCast(feelPosition, castSize, 0f, gravityController.GravityVector, contactFilter, groundHits, 0f);

        for (int i = 0; i < hitCount; i++)
        {

            // ヒットした相手の情報を取得
            RaycastHit2D hit = groundHits[i];

            if (Vector2.Dot(hit.normal, -gravityController.GravityVector) > 0.7f)
            {
                isGrounded = true;
                break;
            }

            Debug.Log($"何かに衝突しました: {hit.collider.name} / 足元の面の法線: {hit.normal}");
        }

        Debug.Log($"接地判定: {isGrounded}");
    }

    /// <summary>
    /// 地面判定を外部から参照できるようにするプロパティ
    /// </summary>
    public bool IsGrounded
    {
        get { return isGrounded; }
    }

    void OnDrawGizmosSelected()
    {
        if (!Application.isPlaying)
        {
            return;
        }
        Vector3 drawSize = new Vector3(castSize.x, castSize.y, 0.01f);
        Gizmos.color = isGrounded ? UnityEngine.Color.green : UnityEngine.Color.red;
        Gizmos.DrawWireCube(feelPosition, drawSize);
    }
}
